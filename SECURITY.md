# Security Policy

## Supported Versions

We actively provide security updates and patches for the latest release branch of RawView.

| Version | Supported          |
| ------- | ------------------ |
| 3.9.x   | :white_check_mark: |
| < 3.9   | :x:                |

## Reporting a Vulnerability

The RawView team takes security and user privacy seriously. If you discover or suspect a security vulnerability, please do **not** report it via public GitHub Issues, pull requests, or public discussions.

### How to Report

1. **GitHub Private Vulnerability Reporting (Recommended)**:
   - Go to the [Security Advisories](https://github.com/jimhpar/RawView_File_Preview/security/advisories) tab of this repository.
   - Click **"Report a vulnerability"** to privately submit your advisory to maintainers.

2. **Direct Contact**:
   - If you are unable to use GitHub Security Advisories, contact the maintainer directly via GitHub profile [@jimhpar](https://github.com/jimhpar).

### What to Include in Your Report

To help us investigate and resolve the issue quickly, please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC) file.
- Your environment details (Windows version, RawView version).
- Any suggested mitigations or fixes, if available.

### Response & Timeline

- **Acknowledgment**: Within **48 hours**.
- **Status Updates**: Progress updates within **3–5 business days**.
- **Fix & Disclosure**: Once a fix is verified, a patch will be published with release notes crediting the reporter (unless anonymity is requested).
